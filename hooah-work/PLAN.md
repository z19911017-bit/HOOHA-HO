# Hooah運動 板橋江翠店：產品路線圖

網站以「雙軌預約」為核心：團體課行事曆預約，以及 1 對 1 客製化減重諮詢。這是一個多功能平台，所以我們先把品牌化的完整前台與後台介面做出來，再分階段接上真實資料、登入與通知。

## ✅ 里程碑 1：產品介面（已完成）
- 首頁：頂部導覽列、全螢幕主視覺輪播（也支援影片背景）、雙 CTA、本週精選課程、減重計畫與成果案例、環境影音牆、師資輪播、交通與 Google 地圖、右下角 LINE 浮動按鈕
- `/schedule` 團體課週課表：依課程類型、時段、教練篩選；顯示「預約中／即將額滿／已額滿」；預約表單（姓名／電話／Email／LINE 提醒）
- `/consult` 減重諮詢預約精靈：服務項目 → 教練 → 時段（45/60 分鐘，09:00–21:00，排除已被預約的空檔）→ 問卷 → 確認
- `/coaches` 師資頁：照片、背景、證照、擅長領域、「立即預約諮詢」（帶入教練）＋「LINE 諮詢教練」
- `/admin` 後台預覽：拖曳排課行事曆、新增／複製週期課程、名冊與簽到、CSV 匯出、新增教練
- 所有資料目前都來自 `src/data/fixtures.ts`

## 🟡 里程碑 2：資料模型（Netlify Database）
- 以 Drizzle 建立資料表：`coaches`、`class_types`、`rooms`、`weekly_slots`（週期規則）、`class_sessions`（實際開課日期，可單堂取消／調整）、`class_bookings`、`consult_services`、`coach_availability`、`consult_bookings`、`media_items`
- 以 seed 帶入目前的範例資料
- 以 TanStack Start server functions 取代 fixtures 的讀取

## 🟡 里程碑 3：真實預約流程
- 團體課預約：交易內檢查名額，避免超賣；同一手機重複預約防護；候補名單
- 1 對 1 諮詢：依教練可預約時段與既有預約計算空檔，送出時再次檢查衝突
- 取消／改期連結（以預約代碼驗證）

## 里程碑 4：通知
- Email 確認信（透過交易郵件服務）
- LINE 提醒：LINE 官方帳號 Messaging API；課前一天以排程函式發送提醒
- 諮詢預約成功後同步通知該位教練與管理員（Email／LINE 群組）

## 🟡 里程碑 5：後台登入與權限
- Netlify Identity：管理員與教練角色；`/admin` 受保護
- 教練只看得到自己的課程名冊與諮詢預約

## 🟡 里程碑 6：後台資料管理
- 將 `/admin` 的排課、複製週期、拖曳、簽到、匯出接上資料庫
- 教練 CRUD（含上傳大頭照／形象照），前台師資版塊自動產生
- 營業時段、諮詢時長、課程類型、教室設定

## 🟡 里程碑 7：媒體與內容管理
- 相片牆與短影音上傳／替換（Netlify Blobs），主視覺影片設定
- 減脂成果案例管理

## 里程碑 8：上線前整理
- 替換真實的 LINE 官方帳號、各教練 LINE、交通與停車資訊
- SEO（LocalBusiness 結構化資料）、分享縮圖、GA／Meta Pixel 轉換追蹤
